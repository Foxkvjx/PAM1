# PAM

Aplicativo editorial de notícias com visual minimalista, busca, categorias, favoritos e autenticação de demonstração.

## Rodar
`npm install`
`npm run dev`

Abra http://localhost:3000.

## Próxima camada
A interface está pronta para conectar uma API de notícias e Supabase Auth/Database sem precisar refazer a experiência visual.
